# SmartSembakoAssistant Project Context

This project is a modular assistant system for store operations automation.

## Main Components

- Telegram Bot Service
- Scheduler Service
- POS Database Service
- AI Processing Layer
- Documentation Modules

---

## Architecture Principles

- Modular services
- Maintainable structure
- Clear separation of concerns
- Minimal coupling
- Scalable implementation phases

- Avoid monolithic files
