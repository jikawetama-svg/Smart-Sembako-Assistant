# 🛒 Smart Sembako Interactive Web Dashboard (Mode Statis Gratis)

Dashboard Web interaktif untuk Aronium POS Smart Sembako Assistant dengan visualisasi omset, kelola stok produk, dan simulasi Telegram Bot offline.

## 🚀 Fitur Utamanya
- **Dashboard Penjualan & Stok**: Visualisasi omset harian, jumlah transaksi, dan alert stok kritis.
- **Kelola Produk**: Tabel produk interaktif dengan pencarian cepat (*live search*).
- **Simulasi Telegram Assistant**: Interaksi tanya-jawab stok dan omset langsung dari browser secara gratis tanpa API key berbayar.
